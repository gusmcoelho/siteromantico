# Site Romântico

Aplicação web interativa para criação, personalização e compartilhamento de convites românticos, cartas especiais e pedidos de namoro.

Acesse o site: https://gusmcoelho.github.io/siteromantico/

## Funcionalidades

- Personalização de mensagens, fotos, perguntas e respostas.
- Temas visuais selecionáveis (Pink Romance, Red Passion, Purple Night, Dark Love, Emerald).
- Efeitos interativos com botões animados e partículas de corações.
- Compartilhamento via link direto e geração de QR Code.
- Reprodução de áudio e trilhas sonoras.

## Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
